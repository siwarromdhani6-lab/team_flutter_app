# team_flutter_app

## Setup (first time)
1) Install Flutter + Android Studio (SDK)
2) Install VS Code + Flutter extension
3) Run:
   flutter pub get

## Run the app
flutter run

## Team workflow (Git)
- Do not work directly on main
- Each task = a new branch (feature/...)
- Push your branch and open a Pull Request

## Branch examples
- feature/login
- feature/home-screen
- fix/button-bug
